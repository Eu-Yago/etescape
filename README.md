# ETEscape — Fuga da Escola

Jogo web em formato **graphic novel** (HTML, CSS e JavaScript), para jogar **deitado** (horizontal).
Há um incêndio na ETESC-RJ e você tem 5 minutos para escapar.

## Como jogar
Abra o `index.html` no navegador (ou use o link do GitHub Pages).

- Clicar/tocar na tela, Espaço ou Enter: avança o texto
- Botões ou teclas 1, 2, 3, 4: escolhem uma opção
- H: esconde o texto para ver a cena · M: liga/desliga o som

## Arquivos
- `index.html`, `style.css`, `game.js`
- `assets/`: imagens (menu, fase_01 a fase_04, char, fx)

Para trocar imagens, veja o objeto `A` no começo do `game.js`.
